PROJECT: Untuk Abang Gala 💗

Isi folder:
- index.html: website utama
- foto-kami.jpg: (tambahkan sendiri) foto kalian berdua

CARA PAKAI:
1. Extract ZIP.
2. Masukkan foto kalian ke folder yang sama dengan index.html, lalu namai persis: foto-kami.jpg
   Jika belum ada foto, halaman tetap berfungsi dan menampilkan placeholder.
3. Buka index.html di browser untuk preview.
4. Buat repository GitHub baru, misalnya `untuk-abang-gala`.
5. Upload index.html dan foto-kami.jpg ke root repository.
6. Buka Settings > Pages.
7. Pada Build and deployment, pilih Deploy from a branch.
8. Pilih branch `main` dan folder `/ (root)`, lalu Save.
9. Tunggu beberapa menit. URL website akan muncul di halaman Settings > Pages.

Catatan:
- Website ini statis, tidak butuh backend atau database.
- Tombol “Enggak mau” bergerak sebagai candaan. Teks di halaman tetap menyatakan bahwa keputusan dan waktu Gala dihargai.
